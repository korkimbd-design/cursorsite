# 혁신 크리에이티브 — 루키 × 일본 재난 대피 안내

## 핵심 아이디어 1: 「따라가면 되는 대피」— Follow-the-Robot Evacuation

### 개요
기존 재난 안내는 **앱 푸시·방송·종이 지도**에 의존합니다. 혁신팀 제안은 **루키가 실제로 앞서 걸어가며** 관광객·당황한 사람이 **「따라가기」만 하면 대피소에 도달**하는 **물리적 안내 경험**입니다.

### 타겟에게 통하는 이유
- **관광객:** 일본어 표지판을 읽지 못해도 **로봇 뒤를 따르면 됨**
- **당황한 인원:** 선택지가 많을수록 마비 → **하나의 행동(따라가기)** 로 단순화
- **근거:** AE 인사이트 「긴 문장을 읽지 않는다」→ **시각·동선 안내**

### 실행 가능성·리스크
| 항목 | 내용 |
|------|------|
| **가능** | 파일럿 5개소, 지자체 대피소 DB 연동 |
| **리스크** | 혼잡 시 추돌 → 속도 제한·정지 센서 필수 |
| **완화** | 「따라오지 않아도」LED·음성으로 방향은 계속 표시 |

### 다른 매체 연계
- **영상:** 따라가는 30초 Hero
- **옥외:** 역 광장 실제 배치
- **이미지:** 「Follow the orange arrow」 키 비주얼

## 핵심 아이디어 2: 「언어 없는 안내 데이」— Silent Drill Day

### 개요
한 달 1회, 관광지에서 **「언어 없이도 이해되는 대피 연습」** 체험. 루키만 움직이고 **말 없이** 화살표·손짓(로봇 암)으로 3분 루트 안내. 참가자는 **말 없이 따라가기**만 하면 됨.

### 타겟에게 통하는 이유
- **체험 = 기억:** 실제 재난 시 「저 로봇 따라가면 됐지」** muscle memory**
- **SNS 확산:** 「일본에서 로봇 따라 걸었어요」 UGC

### 실행 가능성·리스크
| 항목 | 내용 |
|------|------|
| **가능** | 주말 1회, 50명 규모 |
| **리스크** | 연출만 하고 실제 대피소와 불일치 → **실제 避難所까지** 연결 필수 |

### 연계
- **혁신 → 평시 인지 → 재난 시 신뢰** 로 이어지는 **브랜드 스토리**
